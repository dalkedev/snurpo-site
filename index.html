Before you install

The macOS app is ad-hoc signed and is not Apple-notarized.

Native workflows have been exercised on Apple Silicon. Windows and Linux have CI build and headless checks; interactive installers and desktop behavior remain experimental. Intel macOS is unverified.

Bodies are buffered up to 16 MiB each. Streaming, WebSocket frames and HTTP/3 are not implemented.
